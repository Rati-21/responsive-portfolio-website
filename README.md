# responsive-portfolio-website

## Project Overview
This project is a fully responsive, multi-page portfolio website designed to showcase the skills, projects, and experience of a fictional client. It features an intuitive layout, semantic HTML5 structure, modern CSS styling with Grid and Flexbox, and mobile-first responsiveness.

Developed as part of the **WPR171** coursework.
